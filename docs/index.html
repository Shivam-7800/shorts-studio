Connect your GitHub

This page asks your GitHub repo to make the videos. It needs a token that can start the repo’s workflows. The token is saved only in this browser, so other visitors can’t use your channels.

github.com → Settings → Developer settings → Fine-grained tokens. Repository access: only this repo. Permission: Actions, Read and write.

Voice
Your voice on GitHub

Works for English and Hindi. Builds take 10 to 15 minutes because GitHub has to load the voice model. One-time setup: record your voice in the PC app, run python make_voice_secret.py, and save what it copies as the VOICE_SAMPLE_B64 secret.

AI images come from a free service that draws about one picture every 15 seconds, so a 10-scene video takes 2 to 3 minutes longer.

Start from another video

GitHub transcribes the video, then Gemini writes your own version. It never copies the other creator’s words or footage, because reposted content gets channels flagged on YouTube and Instagram.

Dance to the same song

The dancer moves on every beat of the song. The video is silent: you add the same song in the Instagram or YouTube app, so it’s never muted. Use a link (your PC helper downloads it) or upload the video.
